Reports name a block or manifest by its cid, never its content: encrypted blocks can’t be read by hosts or by Fork. A valid report tombstones the cid (cooperating devices delete it and refuse it again). If a host’s upload receipt is attached, it names the account that sent it, which can then be suspended. A modified client can keep a copy.
